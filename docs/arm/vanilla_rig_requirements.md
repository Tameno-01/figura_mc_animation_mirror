# Vanilla arm requirements

The arm must NOT have an elbow joint for this page to apply, if it does, see the [rigged arm requirements](rigged_rig_requirements.md).

The arm must be pointed down (in an I pose).

If there's an implication of a hand, it must be oriented with the thumb facing forward (towards negative Z in blockbench).

Note the distance between the arm's pivot and the would-be hand. You'll need it later. If you're unsure of what this means, place a temporary empty group where the hand would be and note the difference in the Y position between it and the arm's pivot.

The arm can be parented to whatever you want.
