# Implementing your own body

It is possible to implement your own completely custom rig retargeting, but it's very hard and 99.9% of people won't want to do it, so i won't bother documenting it. If you really want to implement a type of body unsupported by Animation Mirror (and you think it's even possible to do so), let me know in the Figura discord forum post i made for this API, and get ready for A LOT of vector and matrix math.
