# Vanilla leg requirements

The leg must NOT have an knee joint for this page to apply, if it does, see the [rigged leg requirements](rigged_rig_requirements.md).

The leg must be pointed down (in an I pose).

If there's an implication of a foot, it must be oriented with the toes facing forward (towards the negative Z axis in blockbench).

Note the distance between the leg's pivot and the would-be foot. You'll need it later. If you're unsure of what this means, place a temporary empty group where the foot would be and note the difference in the Y position between it and the leg's pivot.

The leg can be parented to whatever you want.
