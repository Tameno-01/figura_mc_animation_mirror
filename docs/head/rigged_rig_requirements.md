# Rigged head requirements

The head must be facing forward (towards negative Z in blockbench).

If the neck is present, it should be a direct or indirect parent of the head, and unless you're using a [vanilla-styled torso](../torso/vanilla_rig_requirements.md), should be itself directly or indirectly parented to the torso.

If the neck is not present, and you're not using a [vanilla-styled torso](../torso/vanilla_rig_requirements.md), the head should be directly or indirectly parented to the torso.
